# Architect specifications

The architect writes one `SPEC-C###.md` per new cycle. A principal revision writes `REVISION-C###-R##.md`. Every file is hash-anchored by a decision JSON before the controller may create a builder task.

Specifications must define one bounded enjoyment outcome, explicit construction/interfaces, 3–7 independent acceptance criteria, 1–8 required tests/proofs, scope exclusions, budgets, rollback, and escalation boundaries.
